このファイルは `npm run eval` が作る（手で書き換えない）。評価の方法は README の「分類の評価」を参照。

- 実行日：2026-11-09
- 分類のモデル：`gpt-6-luna`（NGワード、Moderation API と組み合わせた、本番と同じ判定）
- 評価用のコメント：100件（架空。`eval/classification-dataset.json`）、動画のタイトル「ふわとろ親子丼の作り方｜10分でできる簡単レシピ」
- かかった時間：29秒、推定費用：$0.0025

## まとめ

| 指標 | 値 | 意味 |
| --- | --- | --- |
| 正解率 | **99.0%**（99／100件） | 7種の分類が、正解と一致した割合 |
| 要注意の見逃し | **0.0%**（0件） | 要注意のコメントを、他の分類にしてしまった割合。低いほどよい |
| 誤って要注意 | 0.0%（0件） | 要注意ではないコメントを、要注意にしてしまった割合 |

このアプリは、コメントで心を痛めやすい発信者を守るためのものなので、**要注意の見逃しを最も重く見る**。
誤って要注意にした場合は、そのコメントが「要注意」のタブに入るだけで、発信者が傷つくことはないため、ある程度は許す（要件定義書9.1）。
