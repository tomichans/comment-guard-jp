# メイン画面の動作確認（ローカル）

## 準備

1. `npx supabase start`（起動済みなら不要）
2. 新しい列（返信数）を入れるため、`npx supabase db reset` を実行する（ローカルのデータは消えます）
3. `npm run dev` で起動し、Chrome で http://localhost:3000 を開く（ウィンドウの幅は1280px以上）

## 確認すること

### ゲスト

- [ ] 中央に URL の入力欄と「ゲストとして利用中：…24時間で…」の案内が出る
- [ ] でたらめな URL（例：https://example.com）を入れると、赤字でエラーが出る
- [ ] YouTube の動画 URL を入れて「分析する」を押すと、動画のページ（/videos/…）に移り、コメントが並ぶ
- [ ] 左の動画一覧に、その動画が出る（ゲストには削除ボタンは出ない）
- [ ] 「＋新しい動画」を押すと「ゲストは同時に1本までです」の案内が出て、「今の動画に戻る」で戻れる

### コメント一覧

- [ ] 並び順（新しい順／いいねが多い順／返信が多い順）を切り替えると、並びが変わる
- [ ] 検索欄に語を入れて Enter を押すと、その語を含むコメントだけになる。消すと元に戻る
- [ ] 50件より多い動画で、下までスクロールすると続きが読み込まれる
- [ ] 「返信を表示」で返信が開く。YouTube にもっと返信がある場合は「ほかにN件…」と出る
- [ ] ページを再読み込みしても、同じ動画が表示される

### ログインユーザー

- [ ] 左下の「無料で登録する」から登録すると、ゲストの動画がそのまま一覧に残る（引継ぎ）
- [ ] 入力欄の下が「最長29日間保存され…」に変わる
- [ ] コメントが100件より多い動画を登録すると、「残りのコメントを取得しています」と出て、終わると自動で件数が増える
- [ ] 一覧の動画にマウスを乗せるとゴミ箱が出て、確認の後に削除できる
- [ ] 「ログアウト」で、ゲストの表示に戻る

### その他

- [ ] 右の枠に、ランキングと AI アドバイスの「準備中」が出る
